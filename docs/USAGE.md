# 使用指南 —— 构建、开关与注意事项

> **本文回答**：我要保护一个脚本，**敲哪条命令**、**能开哪些功能**、**哪些坑必须先知道**。
>
> 面向**使用者**（拿脚本进来、拿产物出去）。面向**构建者**（想编解释器本身、改插桩点）的
> 文档是 [`BUILD.md`](BUILD.md)（bash 线）与 [`BUILD_MKSH.md`](BUILD_MKSH.md)（mksh 线）。

## 一、三分钟上手

### 1.1 最小可用：不给任何口令

**外层口令不是必需的。** 不传 `V7_OUTER_PASS` 就走**离线分发模式** ——
产物自带白盒编码的密钥种子，**运行方无需任何口令**，双击即跑：

```bash
cd /workspace/shellvmp

# bash 线（改版 bash 由你提供）
V7_MODE=bash V7_BASH_BIN=/path/to/改版bash \
  bash v7/v7_build.sh your_script.sh app.bash

# mksh 线（连解释器都不用预先准备，从源码现场构建）
V7_MODE=mksh V7_MKSH_SRC=./mksh-src \
  bash v7/v7_build.sh your_script.sh app.mksh
```

产物**直接执行**，`V7_SELF=1` 是必须的（见 §四.1）：

```bash
V7_SELF=1 ./app.bash /dev/null
```

### 1.2 加口令：控制"谁能运行"

```bash
V7_MODE=bash V7_BASH_BIN=/path/to/改版bash V7_OUTER_PASS='你的外层口令' \
  bash v7/v7_build.sh your_script.sh app.bash

# 运行：口令错误 → rc=114（认证失败）
V7_SELF=1 V7_PASS='你的外层口令' ./app.bash /dev/null
```

> **口令强度是构建期强校验**（不达标直接 `exit 2`，不会产出弱产物）：
> **≥8 位**，且**字母 / 数字 / 符号三类至少占两类**。
> 理由：KDF 是全链路保密性的终点，弱口令可被 GPU 暴力破解。
>
> 不必再手工设临时目录 —— 脚本已做安卓/Termux 适配（自动归一化 `TMPDIR`）。

### 1.3 两条线的区别（选一个）

| | bash 线 | mksh 线 |
|---|---|---|
| 解释器来源 | 需你提供改版 bash（`V7_BASH_BIN` 或 `V7_SRC` 现场建） | `V7_MKSH_SRC` 现场建，**开箱即用** |
| 产物体积 | 约 965 KB | 约 384 KB（小 **60%**） |
| 目标场景 | 通用 Linux / 服务器 | **Android 真机**（`/system/bin/sh` 就是 mksh） |
| 构建耗时 | 复用二进制约 10 秒 | 现场建解释器约 15 秒（`V7_MKSH_BIN` 复用时约 10 秒） |
| 成熟度 | ✅ 生产可用 | ✅ 可用（一处限制见 §四.2） |

**不确定就先用 mksh 线** —— 它不需要你事先准备任何解释器二进制。

## 二、功能开关总表（实测）

> 下表**每个组合都实测过**（构建 + 运行 + 与明文对拍）。
> 「默认」列指不显式设置时的取值。

### 2.1 核心开关

| 开关 | 取值 | 默认 | 作用 |
|---|---|---|---|
| `V7_MODE` | `bash` / `mksh` / `elf` | 按后缀推断 | 选保护线；`.bash`→bash、`.mksh`→mksh |
| `V7_OUTER_PASS` | 字符串（≥8 位） | 空 | 外层口令。**空 = 离线分发模式（免口令运行）** |
| `V7_PASS` | 字符串 | 空 | 内层 passkey（V6 密钥分离）。⚠️ **mksh 线不可用**，见 §四.2 |
| `V7_ISA` | `0` / `1` | **1** | 令牌化总开关（L1-L4 + L6） |
| `V7_ISA_PARAM` | `0` / `1` | **1** | L6 字符串字面量令牌化（静态字符串 → 密文令牌） |
| `V7_JUNK` / `V7_DECOY` | `0` / `1` | **1** | 垃圾块 / 诱饵块（提升逆向噪声） |
| `ANDROID_GATE` | `0` / `1` | **1** | **脚本侧**安卓环境门控；非安卓环境静默拒绝 |
| `V7_SCRYPT_N` | 整数 | 131072 | 外层 KDF 内存参数 → **与运行耗时强相关，见 §四.3** |
| `ANDROID_GATE=0` | — | — | 桌面/沙箱调试**必须设**，否则产物在非安卓上零输出 |

### 2.2 实测矩阵

| 配置 | 构建 | 运行 | 说明 |
|---|---|---|---|
| bash · 离线 · ISA 默认 | ✅ | ✅ | 最简形态 |
| bash · 离线 · `V7_ISA=0` | ✅ | ✅ | 关令牌化（产物更小、更易排障） |
| bash · 离线 · `V7_ISA_PARAM=0` | ✅ | ✅ | 只关 L6 |
| bash · 离线 · `V7_JUNK=0 V7_DECOY=0` | ✅ | ✅ | 无垃圾/诱饵 |
| bash · 离线 · `ANDROID_GATE=1` | ✅ | ⚠️ | **非安卓环境零输出 = 门控生效**（设计行为） |
| bash · 口令 · `V7_SCRYPT_N=131072`（默认） | ✅ | ⚠️ | **慢机器触发反调试时间窗 rc=113**，见 §四.3 |
| bash · 口令 · `V7_SCRYPT_N=16384` | ✅ | ✅ | **推荐的桌面/调试档** |
| bash · 口令 · 内层口令 | ✅ | ✅ | 需 stdin 供 key，见 §四.4 |
| bash · 锁定 ISA 种子 | ✅ | ✅ | `V7_ISA_SEED=12345` 可复现 |
| mksh · 离线 · ISA 默认 | ✅ | ✅ | |
| mksh · 离线 · `V7_ISA=0` | ✅ | ✅ | |
| mksh · 口令（外层） | ✅ | ✅ | |
| **mksh · 内层口令（`V7_PASS`）** | ✅ | ❌ | **已知限制**，见 §四.2 |

## 三、按场景选配置

| 你的场景 | 推荐命令 |
|---|---|
| **Android 真机部署** | `V7_MODE=mksh V7_MKSH_SRC=./mksh-src V7_OUTER_PASS='口令'` |
| **内网发放、免口令** | `V7_OUTER_PASS` 留空（离线分发模式） |
| **要给客户设口令** | 加 `V7_OUTER_PASS='至少8位'` |
| **桌面先调试通再上真机** | 加 `ANDROID_GATE=0 V7_SCRYPT_N=16384`（**这两个是调试关键**） |
| **要可复现的构建** | 加 `V7_ISA_SEED=固定值`（否则每次构建的表都不同） |
| **产物越小越好** | 用 mksh 线；可再 `V7_ISA=0` |
| **排障（看构建细节）** | 加 `V7_KEEP_STAGE=1`（⚠️ 中间产物含明文语义等价物，**勿分发**） |

### 三个现成的"配方"

```bash
# ① 真机生产档（最强保护）
V7_MODE=mksh V7_MKSH_SRC=./mksh-src \
  V7_OUTER_PASS='你的口令' ANDROID_GATE=1 \
  bash v7/v7_build.sh app.sh app.mksh

# ② 桌面调试档（快速验证逻辑）
V7_MODE=mksh V7_MKSH_BIN=/path/to/改版mksh \
  ANDROID_GATE=0 V7_SCRYPT_N=16384 \
  bash v7/v7_build.sh app.sh app.mksh

# ③ 免口令内网档
V7_MODE=bash V7_BASH_BIN=/path/to/改版bash ANDROID_GATE=0 \
  bash v7/v7_build.sh app.sh app.bash
```

## 四、注意事项（**开工前必读**）

> 这一节的每一条都是**实测踩出来的**，不是推测。
> 按"踩到后有多难察觉"排序 —— 前两条最容易让人以为是自己环境坏了。

### 4.1 ★ 运行契约：必须带 `V7_SELF=1` **和** 一个 argv 文件参数

**两件事都要做，缺一不可：**

```bash
V7_SELF=1 V7_PASS='口令' V7_ISA_TABLE=app.bash.isa.bin ./app.bash /dev/null
#          ↑必需       ↑带 ISA 时必需              ↑必需（惯例 /dev/null）
```

| 漏了什么 | 症状 | 为什么 |
|---|---|---|
| 漏 `V7_SELF=1` | **静默 rc=0、零输出** | 不设它，改版解释器不知道自己被内嵌，不会去读尾部载荷 |
| 漏 argv 文件参数 | 静默 rc=0 零输出 / rc=127 | 解释器进 **stdin 模式**，读不到脚本文件 ⇒ 解密分支根本不被走到 |
| 漏 `V7_ISA_TABLE` | 输出里出现 `v7p_xxx: command not found` | 令牌化后的命令名无处还原（**静默降级，不是崩溃**） |

> **产物是 ELF，要"直接执行"**：`./app.bash` ✅ ／ `bash app.bash` ❌
> 后者会让 `/proc/self/exe` 指向**解释器**而非产物，解密必然不触发。
>
> 症状之所以危险：**它和"解密失败""口令错误""完整性拒绝"长得一模一样**
> （都是静默 rc）。排障时**先排除这三条**，再去怀疑加密逻辑。

### 4.2 ⚠️ mksh 线不能用内层口令（已知限制，未修复）

```bash
# ❌ 这样构建出来的产物跑不起来
V7_MODE=mksh ... V7_PASS='内层key' ...      # 运行报 read: -p: no coprocess，rc=1
```

**根因**：V6 骨架用 `IFS= read -rs -p 'Key: '` 读内层口令，而 `-p` 在两个
shell 里语义**相反** —— bash 是"prompt 字符串"，mksh 是"**从 coprocess 读**"。

| | 外层口令 `V7_OUTER_PASS` | 内层口令 `V7_PASS` |
|---|---|---|
| bash 线 | ✅ 可用 | ✅ 可用 |
| **mksh 线** | ✅ **可用** | ❌ **不可用** |

**怎么办**：mksh 线用**外层口令**或**离线模式**即可，安全强度不受影响 ——
内层口令是"口令 × 口令"的叠加，不是必需层。构建脚本检测到这个组合会
**主动打印警告**，不会让你拿到一个跑不通的产物还以为是自己环境的问题。

### 4.3 ⚠️ 慢机器 + 外层口令 → rc=113（反调试误伤，**非缺陷**）

```bash
$ V7_SELF=1 V7_PASS='口令' ./app.bash /dev/null
rc=113        # 什么都没输出
```

**成因**：外层口令档要跑 scrypt KDF，默认 `V7_SCRYPT_N=131072`（16 MB 内存参数）。
实测在较慢的机器上单这一项就花 **3.4 秒**，超过反调试的
**启动→解密时间窗 3000 ms** 阈值 ⇒ 被判为"断点/单步调试" ⇒ `exit 113`。

> **这是设计行为**：时间窗是用来防"下断点单步跟解密"的。
> 但快慢是相对的 —— 同一份产物在桌面秒开，在低端机上就被误伤。

**三条出路**（按推荐顺序）：

| 方式 | 效果 |
|---|---|
| `V7_SCRYPT_N=16384` | 实测降到 0.84 s，正常输出。**桌面/沙箱调试首选** |
| 走**离线分发模式**（不给 `V7_OUTER_PASS`） | 实测 1.0 s，正常输出（不经 KDF） |
| 目标机性能足够（真机/服务器） | 保持默认 131072 最安全 |

> **自查**：构建日志里搜 `分发模式` —— 写着"口令模式"就受这条影响，
> 写着"离线分发模式"就不受。运行耗时用 `time` 一量便知。

### 4.4 内层口令要走 stdin

```bash
echo '内层key' | V7_SELF=1 V7_PASS='外层口令' ./app.bash /dev/null
#    ↑ 内层 key 从 stdin 给
```

内层口令（`V7_PASS`）**不写在命令行里**，交互式从终端读。非交互场景要
`echo` 管道喂进去。构建时忘了给，运行会反复要三次然后放弃。

### 4.5 `ANDROID_GATE` 与"编译安卓版"是两回事

名字像，作用域**完全不同**，混起来会白忙：

| 开关 | 作用域 | 含义 |
|---|---|---|
| `ANDROID_GATE=1` | **脚本侧**（V6 注入的代码） | 产物启动时的**环境门控**：非安卓直接静默拒绝 |
| `TARGET_OS=Android` | **C 侧**（mksh 构建分支） | mksh 自身的平台适配；**本身不产生交叉编译** |

**桌面调试必须 `ANDROID_GATE=0`**，否则产物在非安卓环境零输出，
而你会以为是加密坏了。真正的交叉编译靠 `V7_CC` / `V7_ARCH`。

### 4.6 幂等性：产物 hash 每次都不一样（**特性，不是 bug**）

```bash
# 同一份脚本连跑两次，产物大小/hash 都不同
```

原因有二：ISA 表会随机化"掺假条目"，L6 令牌名每次构建随机生成。
**想复现**就锁种子：

```bash
V7_ISA_SEED=12345 ...     # 表可复现；L6 令牌名仍随机
```

**验证一致性不要比 hash**，要比**运行输出**（rc + stdout + stderr）。

### 4.7 `V7_KEEP_STAGE=1` 的产物不能外发

保留的中间产物包含**明文的语义等价物**（改写版脚本、V6 骨架、表 JSON）。
排障用没问题，**别把它和产物一起打包发出去**。

### 4.8 构建前先体检你的脚本

```bash
python3 tools/v6_lint.py your_script.sh          # 静态兼容性检查
python3 tools/v6_lint.py your_script.sh --strict # 有问题即 exit 1（可挂 CI）

python3 tools/argv_leak_scan.py your_script.sh   # 扫 argv 泄漏点
```

`v6_lint` 会揪出**会静默炸掉产物**的写法：宿主的 `errexit`、`set -x`、
改 `PS4`、重定义 builtin —— 这些会命中产物的**反调试指纹** → 主密钥污染 →
**静默 exit、零提示**。构建时这两个检查默认已开（`V7_LINT=1` / `V7_ARGV_SCAN=1`）。

## 五、验证产物（**别只看"文件生成了"**）

**唯一可靠的功能判据是"逐字节对拍"** —— 原脚本 vs 产物，比
**rc + stdout + stderr** 三元组：

```bash
ref=$(ANDROID_GATE=0 bash your_script.sh 2>&1; echo "rc=$?")
new=$(V7_SELF=1 V7_PASS='口令' V7_ISA_TABLE=app.bash.isa.bin \
      ./app.bash /dev/null 2>&1; echo "rc=$?")
[ "$ref" = "$new" ] && echo "✅ 一致" || diff <(echo "$ref") <(echo "$new")
```

> **为什么不能只看"跑起来了"**：混淆系统里"能跑通"和"结果正确"是两件
> 完全不同的事 —— 令牌没还原会输出假名、块边界错了会截断，都可能 rc=0。

辅助判据：

| 检查 | 命令 |
|---|---|
| 磁盘上无明文 | `grep -c '脚本里的独特字符串' app.bash` → 应为 0 |
| 字节账目自洽 | `产物大小 − 解释器大小 == 骨架大小 + 812` |
| 产物确实是 ELF | `file app.bash` |

## 六、退出码速查

| 码 | 含义 | 先查 |
|---|---|---|
| **0** | 正常 | — |
| **113** | 反调试拒绝 | §4.3 时间窗（**先怀疑这条**）；再查 `TracerPid` / `PS4` 被改 |
| **114** | 认证失败 | 口令错 **或** 产物被篡改（**二者不可区分**，见 [`THREAT_MODEL.md`](THREAT_MODEL.md)） |
| **121** | 裸环境缺工具 | 目标机缺 `gzip` / `sha512sum` / `awk` 等 |
| **132** | SIGILL | VMP 相关（仅 aarch64 + `V7_VMP=1`） |

> ⚠️ **零输出时不要只看退出码**。漏 `V7_SELF=1` 或漏 argv 参数时，
> **rc 是不确定的**（实测见过 0、1、127）—— 取决于 stdin 里恰好有什么内容：
> 空则 rc=0/1，有内容则被当命令执行、可能 127。
> **判据是"零输出"这个现象本身**，不是某个具体码（见 §4.1）。

## 八、完整开关清单

```bash
bash v7/v7_build.sh -h        # 全部开关与说明（从脚本注释实时生成）
```

高频补充：

| 开关 | 作用 |
|---|---|
| `V7_DIAG=1` | 排障版构建（产物运行时设 `V7_DIAG=1` 打印阶段进度与拒绝原因） |
| `V7_LINT=0` | 关闭构建前 V6 兼容性检查 |
| `V7_LINT_STRICT=1` | 检查发现问题即阻断（默认只警告） |
| `V7_ARGV_SCAN=0` | 关闭 argv 泄漏扫描 |
| `V7_UNWRAP_ITER` / `V7_L1_ITER` | 内层解包裹 / 一层壳迭代次数（**调低可提速**，代价是强度） |
| `V7_ARCH` / `V7_CC` | 目标架构 / 交叉编译器 |
| `V7_MKSH_BIN` | 复用已构建的改版 mksh（跳过构建，秒级重打包） |
