# V6 设计：混淆算法层

> **核心目标**：让"解出脚本"必须**真实执行**，而不是静态推导。

---

## 一、五阶段流水线

```
split_into_blocks       按语法结构切分（保证每块可独立 eval）
      ↓
compile_v5              每块 → 密文（AES-256-CTR，逐项独立密钥流）
      ↓
prepare_passkeys        密钥分离（可选）：包裹主密钥 M
      ↓
generate_output_v6      生成"随机化解释器" + 两表结构
      ↓
compact_output_file     压缩（贪心合并）
      ↓
inject_integrity_hash   完整性三重自校验
      ↓
inject_hself            骨架自哈希 H_skel
      ↓
finalize_layer1         一层壳（**必须最后**）
```

> **顺序敏感**：`finalize_layer1` 若不在最后，一层壳会被后续步骤破坏。

### 各阶段的关键点

| 阶段 | 关键点 |
|---|---|
| `split_into_blocks` | 用**魔改 bash 的 `-n`** 判定每块语法自洽（fail-closed） |
| `compile_v5` | 四种加密原语轮换（`md` 0-3） |
| `gen_randomized_interpreter` | 每次生成都重命名内部变量 + 切换控制流变体 |
| `finalize_layer1` | `P1 = sha512(_SEED + H_skel + _e1 + "\|" + _e2 + M)[0:64]` |

## 二、两表结构

```
_c[]   加密指令批表     \x01 分隔，INST_BATCH=16 条/批
_d[]   加密数据块表     六行同构：
                       det / beacon / 原码 / rt=$_ rc=$? / _s / _ck
```

**为什么要"批"**：一次 openssl 调用解密整批（16 条指令），运行期进程数降到 1/16。

## 三、三个核心机制

### 3.1 执行状态绑链（`_s`）

```bash
# 块 i 的 _s 由三个【真实执行状态】构成
_s = f( rt, rc, pp )

#   rt = $_   上一条命令的最后一个参数
#   rc = $?   上一条命令的退出码
#   pp        执行路径  0=eval / 1=fd here-string / 2=process-sub

# ★ 六种排列随机选一（防模式识别）
```

**效果**：攻击者**不能静态推导**——必须真实执行前一块，并得到相同的 `$?`/`$_`。

**这也解释了为什么"沙箱置换攻击"无效**：把 `curl` 换成 `true` 桩 → `$?` 变了 → 密钥链断在那一刻。

### 3.2 跳跃式密钥链（`JUMP_DIST = 7`）

```bash
# 第 N 块额外掺入【第 N-7 块】的 _ck
if [ "$i" -ge "$JUMP_DIST" ]; then
    jump_ck="${CK_HISTORY[$((i - JUMP_DIST))]:-}"
fi

# _ck = sha512(chainkey + _sl + index + chainkey)[0:96]  取 16 字符
# 1/3 概率双重哈希
```

**为什么用"跳跃"而不是"线性前一块"**：

| 依赖方式 | 从中间 dump 后能否向后重建 |
|---|---|
| 只依赖前一块 | ⚠️ **能**（只要知道当前状态） |
| 跳跃引用第 N-7 块 | ✅ **不能** → 必须**从头完整执行** |

### 3.3 批级自修改（`_am`）

```bash
_am() {
    # LCG 推进
    _rs = (_rs * 1103515245 + 12345) & 0x7fffffff
    RANDOM=$_rs                          # 重播种 bash 的 RANDOM
    _ra=$RANDOM; _rb=$RANDOM             # 消费两次

    _mk = sha512(_mk + _p + _ra + _rb)[0:16]
    _c[$_p] = $(_e "$_b" "$_mk" "$_p")   # 重加密整批
}
```

**效果**：内存 dump **一次性**——即使拿到某刻密钥，下一秒就变。

## 四、`$RANDOM` 状态机模拟器

**为什么需要**：编译期要**模拟执行**用户代码捕获状态，模拟器里的 `$RANDOM` 序列必须与运行期**逐字节一致**。差一个数，整个密钥链分叉。

**bash 5.1+ `lib/sh/random.c` 的真实行为**：

```c
// Park-Miller Schrage 法
brand: ((rseed >> 16) ^ (rseed & 65535)) & 32767

// ★ 去重循环（极易漏）
do { rv = brand(); } while (rv == last);
```

> **换语言时，自带一个三行 LCG 更省事。** 别学 bash 的复杂度。

## 五、伴生机制

### 5.1 不透明谓词

```
类型 0-3  恒真：  di+1  /  di*di+1  /  di+di+2  /  di*2+1
类型 4-7  恒假
```

**只用 `+ - *`**，避开 `==`/`%`——不同 awk 变体行为不一致。

### 5.2 诱饵块 vs 垃圾块

| 类型 | 行为 | 成本 |
|---|---|---|
| **诱饵块**（DECOY_LEVEL） | 走恒假谓词，**零执行** | 低 |
| **垃圾块**（JUNK_LEVEL） | 走**完全相同**的 `compile_v5` 路径，**真实 eval**，参与密钥链 | 高 |

**垃圾块的价值**：AI 重放 VM 时**一个都跳不过去**，只能逐块解密求值，上下文/压缩次数成倍增长。

垃圾块的 **5 条硬约束**：
1. 必须真实可执行
2. 对原始代码零影响
3. 参与密钥链
4. 结构必须与真实块**完全同构**
5. 每块推进密钥链

### 5.3 契约名随机化

```bash
N_OS / N_S5 / N_S2 / N_SL / N_C / N_D / N_RS / N_MK / N_CK / N_DI / N_PP ...
```

**关键坑**：`gen_rand_var` 的注册表**必须落文件**——子 shell 的 `+=` 不回传。

### 5.4 命名空间（`V6_NS`）

```bash
V6_NS=yourname   →   产物里是 yourname_k9x2（每次构建后缀不同）
```

**设计约束**：
- 只做前缀拼接，**不参与任何密钥派生**
- 未设置时行为与历史版本**逐字节一致**
- 前缀必须合法标识符，最长 24 字符

**为什么不做成完全固定**：随机变量名的**唯一价值**就是"不固定"。固定 = 永久锚点。

### 5.5 完整性三重自校验

```
d0 内嵌 @@INTEGRITY_HASH@@
归一化比对：N_D[0] / _I / _hs 三处
用 index/substr 纯字符串替换（不用正则 —— awk 变体差异）
```

### 5.6 一层壳

```
P1 = sha512(_SEED + H_skel + _e1 + "|" + _e2 + M)[0:64]
H_skel = sha512(骨架文件，_I/_hs 双归一化)[0:128]
```

**效果**：改骨架任何一字节都必须完整重放 PBKDF2 才能重加密。

## 六、密钥分离（PASSKEY_MODE）

```
编译期:
  生成随机主密钥 M（256bit）
  用 M 派生 P1 → 加密脚本
  用 passkey 包裹 M（PBKDF2）
  ← M【绝不写入产物】

运行期:
  read -s passkey → 解包裹 → M → P1 → 解密
```

**信息论意义**：产物里**不包含解密所需的全部信息**。没有 passkey，即使完全理解算法也无法解密。

**这是本项目唯一"消除可能"（而非"提高成本"）的设计。**

## 七、选项速查

| 变量 | 默认 | 作用 |
|---|---|---|
| `JUNK_LEVEL` | 0 | 真执行垃圾块数（每真实块后注入 N 个） |
| `DECOY_LEVEL` | 0 | 诱饵块数（恒假谓词，零执行） |
| `L1_ITER` | 600000 | 一层 PBKDF2 迭代 |
| `KEY_ENTROPY` | 2 | 环境熵等级（2 = 绑定 Android 大版本） |
| `INST_BATCH` | 16 | 每批指令数 |
| `CRYPTO_MODE` | aes | `aes` / `builtin`（零 openssl 依赖） |
| `PASSKEY_MODE` | 0 | 密钥分离 |
| `PASSKEY_COUNT` | 1 | 生成密钥个数（1-16） |
| `UNWRAP_ITER` | 10000 | 解包裹迭代（防离线爆破） |
| `HOST_BIND` | 0 | 绑定本机（产物仅本机可跑） |
| `ANDROID_GATE` | 0 | 安卓门控 |
| `AI_GUARD` | 0 | 抗 AI 声明 |
| `V6_NS` | （空） | 命名空间前缀 |
| `V6_LINT_AGGRESSIVE` | 0 | 激进中和模式 |
